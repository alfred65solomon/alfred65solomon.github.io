Privacy policy

Last updated: October 21, 2026

Alfred is a private, single-user personal assistant. Its only user is the person who built it. This policy explains how the app handles Google user data.

Data the app accesses

With the user's consent, Alfred requests two read-only Google permissions: view Google Calendar events (calendar.readonly) and view Gmail messages and settings (gmail.readonly). It cannot modify, send or delete anything.

How the data is used

Google user data is used only to provide the assistant's features to its single user: detecting calendar conflicts, preparing daily and weekly summaries, and flagging email that needs attention. To produce summaries, relevant text may be processed by an AI language model on the user's behalf.

How the data is stored

Data is stored on a private computer in the user's home. Backups are encrypted. Access credentials are kept in the computer's secure keychain and in a password manager, never in public code.

Sharing

Google user data is not sold, not shared with advertisers or data brokers, not used for advertising, and not used to develop or train generalized AI or machine-learning models. It is not shared with anyone other than the user, except as needed to produce summaries through the AI service described above.

Retention and deletion

Data is kept only as long as needed for the assistant's features. The user can revoke access at any time at myaccount.google.com/permissions and delete stored data from the computer.

Limited Use

Alfred's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
